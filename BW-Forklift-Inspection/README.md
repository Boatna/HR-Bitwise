## 🚜 รายการตรวจเช็คตามประเภทรถโฟล์คลิฟท์

ระบบแบ่งรถโฟล์คลิฟท์ออกเป็น 2 ประเภทหลัก โดยหน้าตรวจเช็คจะสลับหัวข้อและเกณฑ์การตรวจให้อัตโนมัติ:

### 1. แบบน้ำมัน+แก๊ส (Combustion Engine: Oil / Diesel / LPG) — 14 ข้อ
1. **ระดับน้ำมันเครื่อง** — ดึงก้านวัดขณะดับเครื่อง ระดับอยู่ระหว่างขีด Min-Max น้ำมันไม่ดำข้นเหนียวหรือมีตะกอน
2. **ระดับน้ำหม้อพักน้ำ** — ระดับน้ำยาหล่อเย็นอยู่ในระดับ Full/Max ฝาปิดแน่นสนิท ครีบหม้อน้ำไม่อุดตัน ไม่มีรอยรั่ว
3. **ระดับน้ำมันเบรค + ครัช** — ระดับน้ำมันในกระปุกอยู่ในเกณฑ์ที่กำหนด กระปุกไม่แตกร้าว ไม่มีคราบน้ำมันรั่วซึม
4. **ระดับน้ำกลั่น** — น้ำกลั่นท่วมแผ่นธาตุทุกช่อง ฝาจุกปิดสนิท ขั้วแน่น ไม่มีคราบขี้เกลือเกาะหนา
5. **ระดับน้ำมันไฮดรอลิค** — ตรวจเช็คขณะวางงาแนบพื้นราบ ระดับน้ำมันอยู่ในเกณฑ์ตาแมว/ก้านวัด สีน้ำมันใสไม่ขุ่น
6. **เสาและงา** — งาทั้งสองข้างไม่คดงอหรือแตกร้าว ปลายงาเสมอกัน สลักล็อกงาอยู่ครบ เสาเลื่อนขึ้น-ลงราบเรียบ
7. **สภาพล้อ + ยาง** — หน้ายางไม่ฉีกขาด ไม่มีเศษหิน/โลหะฝัง น็อตล้อขันแน่นครบทุกตัว กระทะล้อไม่บิดเบี้ยว
8. **สภาพสายไฮดรอลิค** — สายไฮดรอลิคไม่บวม ไม่แตกลายงา ไม่มีรอยเสียดสี ข้อต่อท่อไม่มีน้ำมันซึมออกมา
9. **ระบบไฟสัญญาณ + แตร** — ไฟหน้า ไฟท้าย ไฟถอย ไฟฉุกเฉิน และแตรทำงานติดครบทุกฟังก์ชัน เสียงดังชัดเจน
10. **ระบบเบรค** — เบรคเท้ากดแล้วหน่วงหยุดได้ดี ไม่จมมิด เบรคมือ/เบรกล็อกล้อทำงานสมบูรณ์ ล็อกรถอยู่สนิท
11. **กระจกมองข้าง** — กระจกซ้าย-ขวาไม่แตกหรือมัว ปรับมุมมองเห็นด้านหลังได้ชัดเจน ขาจับแน่นไม่สั่นคลอน
12. **พวงมาลัย** — บังคับเลี้ยวได้ราบเรียบ ระยะฟรีพวงมาลัยเหมาะสม ลูกบิดพวงมาลัยแน่นหนา ไม่มีเสียงดัง
13. **เข็มขัดนิรภัย** — สายเข็มขัดไม่ฉีกขาด กลไกดึงล็อกกระตุกทำงานดี หัวล็อกแน่นไม่หลุดเอง
14. **สภาพโซ่** — โซ่ยกตึงเท่ากันทั้งสองข้าง ไม่หย่อน ข้อต่อโซ่ไม่บิดเบี้ยวหรือตาย มีการหล่อลื่นเหมาะสม

---

### 2. แบบไฟฟ้า (Electric Forklift) — 10 ข้อ
1. **ระดับน้ำกลั่นแบตเตอร์รี่** — ลูกลอยวัดระดับน้ำกลั่นลอยปกติ น้ำกลั่นท่วมแผ่นธาตุทุกเซลล์ ไม่มีสภาพแห้ง
2. **ขั้วแบตเตอร์รี่** — ขั้วต่อแน่น สะอาด ปราศจากคราบขี้เกลือสะสม ฝาครอบขั้วปิดเรียบร้อย สายไฟไม่ไหม้
3. **ปลั๊กชาร์จไฟ** — หัวปลั๊ก (Connector) ไม่แตกร้าว ขั้วทองแดงด้านในไม่ไหม้เกรียม เสียบต่อแน่นหนา
4. **เสาและงา** — งาไม่คดงอหรือแตกร้าว ปลายงาได้ระดับระนาบเดียวกัน สลักล็อกงาล็อกแน่น เสายกไม่ติดขัด
5. **สภาพล้อ + ยาง** — ยางตัน/ยางโพลียูรีเทนไม่บิ่นแหว่ง ไม่แตกลายงา น็อตขันแน่นครบทุกตัว
6. **ระดับน้ำมันไฮดรอลิค** — วางงาลงต่ำสุด เช็คระดับน้ำมันในถังไฮดรอลิคให้อยู่ในขีดปกติ ไม่มีคราบรั่วซึม
7. **ระบบไฟสัญญาณ + แตร** — ไฟส่องสว่างหน้า ไฟถอย ไฟกะพริบเตือน และแตรทำงานปกติทุกฟังก์ชัน เสียงชัดเจน
8. **สภาพสายไฮดรอลิค** — สายไฮดรอลิคไม่ปริแตก ไม่บวม ข้อต่อท่อไม่มีน้ำมันหยดหรือซึม
9. **สภาพโซ่** — โซ่ยกตึงเท่ากันทั้งสองข้าง ไม่หย่อน ข้อต่อไม่ตาย มีการหล่อลื่นด้วยจาระบี/น้ำมันเหมาะสม
10. **ระบบเบรค** — แป้นเบรคทำงานปกติ ระบบเบรคไฟฟ้า/เบรคมือล็อกอยู่สนิทเมื่อจอดหรือปล่อยคันเร่ง

## 🚀 วิธีตั้งค่า Google Sheets และ Google Apps Script

1. **สร้าง Google Sheet**:
   - นำไฟล์ `ระบบตรวจเช็คโฟล์คลิฟท์.xlsx` ไปอัปโหลดขึ้น Google Drive แล้วเปิดเป็น Google Sheets (หรือสร้าง Google Sheet ใหม่แล้วตั้งชื่อชีตตามนี้: `Employees`, `Forklift`, `Checklist`, `Inspection_Logs`, `Management`, `Cleaning`)
2. **เปิด Apps Script**:
   - ใน Google Sheet ไปที่เมนู **ส่วนขยาย (Extensions)** > **Apps Script**
   - ลบโค้ดเดิมออกทั้งหมด แล้วคัดลอกโค้ดจากไฟล์ `Code.gs` ไปวาง
   - กดบันทึก (Save 💾)
3. **เตรียมข้อมูลเริ่มต้น (Seed Data)**:
   - ที่แถบด้านบนของ Apps Script เลือกฟังก์ชัน `seedForkliftSample` แล้วกด **เรียกใช้ (Run)** เพื่อสร้างข้อมูลพนักงาน รถโฟล์คลิฟท์ และรายการตรวจทั้ง 14 และ 10 ข้อ
   - (ตัวเลือกเพิ่มเติม) เลือกฟังก์ชัน `seedTestData` แล้วกด **เรียกใช้ (Run)** เพื่อสร้างประวัติการตรวจทดสอบ 7 วันสำหรับดู Dashboard
4. **Deploy เป็น Web App เพื่อรับ API**:
   - คลิกปุ่มสีน้ำเงิน **ทำให้ใช้งานได้ (Deploy)** > **การทำให้ใช้งานได้รายการใหม่ (New deployment)**
   - คลิกที่รูปฟันเฟือง ⚙️ เลือกประเภท **เว็บแอป (Web app)**
   - ตั้งค่าดังนี้:
     - **คำอธิบาย (Description):** Forklift Inspection API
     - **ดำเนินการในฐานะ (Execute as):** ฉัน (Me)
     - **ผู้มีสิทธิ์เข้าถึง (Who has access):** ทุกคน (Anyone) *(สำคัญมาก! เพื่อให้เว็บจากภายนอกหรือ GitHub Pages ส่งข้อมูลมาบันทึกได้)*
   - คลิก **ทำให้ใช้งานได้ (Deploy)** และคัดลอก **URL เว็บแอป (Web app URL)** ไว้ เช่น `https://script.google.com/macros/s/.../exec`
5. **ผูก URL ในโค้ด (ไม่ต้องกดตั้งค่าในหน้าเว็บ):**
   - เปิดไฟล์ `app.js` บรรทัดที่ 8 แล้วนำ Web App URL มาใส่ที่ตัวแปร:
     ```javascript
     const GOOGLE_APPS_SCRIPT_URL = 'https://script.google.com/macros/s/.../exec';
     ```
   - จากนั้นตัวระบบจะเชื่อมต่อ Google Sheet ให้โดยตรงอัตโนมัติทันที

## 💻 วิธีเปิดใช้งานใน VS Code และโฮสต์บน GitHub Pages

### 1. เปิดทดสอบใน VS Code
- เปิดโฟลเดอร์ `Forklift Inspection` ใน VS Code
- ติดตั้งส่วนขยาย **Live Server** (โดย Ritwick Dey)
- คลิกขวาที่ไฟล์ `index.html` > เลือก **Open with Live Server**
- เมื่อหน้าเว็บเปิดขึ้น:
  - สามารถทดสอบเข้าสู่ระบบได้ทันที (ใช้ PIN: `1234` หรือ `5678`)
  - คลิกที่ปุ่ม **⚙️ สถานะ API** มุมขวาบน เพื่อนำ Web App URL จาก Google Sheets มาวางแล้วกด "ทดสอบและบันทึก"

### 2. โฮสต์ขึ้น GitHub Pages
1. สร้าง New Repository ใน [GitHub](https://github.com)
2. อัปโหลดไฟล์ทั้งหมดขึ้น Repository:
   ```bash
   git init
   git add .
   git commit -m "Initial commit for Forklift Inspection System"
   git branch -M main
   git remote add origin <URL-GITHUB-REPO-ของคุณ>
   git push -u origin main
   ```
3. เปิดไปที่ **Settings** ของ Repository บน GitHub > เมนู **Pages**
4. ที่ส่วน **Build and deployment**:
   - Source: เลือก **Deploy from a branch**
   - Branch: เลือก **main** และโฟลเดอร์ **/ (root)**
   - กด **Save**
5. รอ 1-2 นาที คุณจะได้ URL เว็บไซต์ เช่น `https://<username>.github.io/<repo-name>/`
6. เปิดหน้าเว็บ เข้าไปคลิกที่ปุ่ม **⚙️** แล้ววาง Web App URL ของ Google Sheets เพื่อเชื่อมต่อฐานข้อมูลได้ทันที!
