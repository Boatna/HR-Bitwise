## 🚜 รายการตรวจเช็คตามประเภทรถโฟล์คลิฟท์

ระบบแบ่งรถโฟล์คลิฟท์ออกเป็น 2 ประเภทหลัก โดยหน้าตรวจเช็คจะสลับหัวข้อและเกณฑ์การตรวจให้อัตโนมัติ:

### 1. แบบเครื่องยนต์ดีเซล (Diesel Engine) — 14 ข้อ
1. **ระดับน้ำมันเครื่อง** — ดึงก้านวัดขณะดับเครื่อง ระดับอยู่ระหว่างขีด Min-Max น้ำมันไม่ดำข้นเหนียวหรือมีตะกอน
2. **ระดับน้ำหม้อพักน้ำ** — ระดับน้ำยาหล่อเย็นอยู่ในระดับ Full/Max ฝาปิดแน่นสนิท ครีบหม้อน้ำไม่อุดตัน ไม่มีรอยรั่ว
3. **ระดับน้ำมันเบรค + ครัช** — ระดับน้ำมันในกระปุกอยู่ในเกณฑ์ที่กำหนด กระปุกไม่แตกร้าว ไม่มีคราบน้ำมันรั่วซึม
4. **ระดับน้ำกลั่น** — น้ำกลั่นท่วมแผ่นธาตุทุกช่อง ฝาจุกปิดสนิท ขั้วแน่น ไม่มีคราบขี้เกลือเกาะหนา
5. **ระดับน้ำมันไฮดรอลิค** — ตรวจเช็คขณะวางงาแนบพื้นราบ ระดับน้ำมันอยู่ในเกณฑ์ตาแมว/ก้านวัด สีน้ำมันใสไม่ขุ่น
6. **เสาและงา** — งาทั้งสองข้างไม่คดงอหรือแตกร้าว ปลายงาเสมอกัน สลักล็อกงาอยู่ครบ เสาเลื่อนขึ้น-ลงราบเรียบ
7. **สภาพล้อ + ยาง** — หน้ายางไม่ฉีกขาด ไม่มีเศษหิน/โลหะฝัง น็อตล้อขันแน่นครบทุกตัว กระทะล้อไม่บิดเบี้ยว
8. **สภาพสายไฮดรอลิค** — สายไฮดรอลิคไม่บวม ไม่แตกลายงา ไม่มีรอยเสียดสี ข้อต่อท่อไม่มีน้ำมันซึมออกมา
9. **ระบบไฟสัญญาณ + แตร** — ไฟหน้า ไฟท้าย ไฟถอย ไฟฉุกเฉิน และแตรทำงานติดครบทุกฟังก์ชัน เสียงดังชัดเจน
10. **ระบบเบรค** — เบรคเท้ากดแล้วหน่วงหยุดได้ดี ไม่จมมิด เบรคมือ/เบรกล็อกล้อทำงานสมบูรณ์ ล็อกรถอยู่สนิท
11. **กระจกมองข้าง** — กระจกซ้าย-ขวาไม่แตกหรือมัว ปรับมุมมองเห็นด้านหลังได้ชัดเจน ขาจับแน่นไม่สั่นคลอน
12. **พวงมาลัย** — บังคับเลี้ยวได้ราบเรียบ ระยะฟรีพวงมาลัยเหมาะสม ลูกบิดพวงมาลัยแน่นหนา ไม่มีเสียงดัง
13. **เข็มขัดนิรภัย** — สายเข็มขัดไม่ฉีกขาด กลไกดึงล็อกกระตุกทำงานดี หัวล็อกแน่นไม่หลุดเอง
14. **สภาพโซ่** — โซ่ยกตึงเท่ากันทั้งสองข้าง ไม่หย่อน ข้อต่อโซ่ไม่บิดเบี้ยวหรือตาย มีการหล่อลื่นเหมาะสม

#### 1.2 แบบเบนซิน+แก๊ส LPG (Petrol + LPG) — 20 ข้อ
*(ข้อ 1–14 เหมือนกับแบบดีเซล พร้อมเพิ่มจุดตรวจระบบก๊าซอีก 6 ข้อ ดังนี้)*
15. **สภาพถังก๊าซ** — ต้องไม่มีร่องรอยบุบ แตก สนิม หรือความเสียหายของถังก๊าซ
16. **การยึดถังก๊าซ** — ถังอยู่ในตำแหน่งที่ถูกต้องและอุปกรณ์ยึดถังอยู่ในสภาพสมบูรณ์
17. **สภาพสายส่งก๊าซ** — ต้องไม่มีรอยแตกร้าว ฉีกขาด บิดงอ หรือเสื่อมสภาพของสาย
18. **ข้อต่อและอุปกรณ์เชื่อมต่อก๊าซ** — ต้องไม่มีรอยแตกร้าว บิดเบี้ยว ไม่หลวม อยู่ในสภาพสมบูรณ์ ซีลไม่ฉีกขาดหรือเสื่อมสภาพ
19. **การรั่วซึมของก๊าซ** — ต้องไม่มีกลิ่นก๊าซหรือสัญญาณผิดปกติที่อาจบ่งชี้ว่ามีก๊าซรั่ว
20. **มาตรวัดระดับก๊าซ** — หน้าปัดไม่แตกร้าว ขุ่นมัว เข็มไม่หัก หรือค้างผิดปกติ ระดับก๊าซเพียงพอต่อการใช้งาน

### 2. แบบไฟฟ้า (Electric Forklift) — แยกย่อยตามประเภทรถยก 2 กลุ่ม

#### 2.1 รถยกไฟฟ้าประเภท Reach truck — 10 ข้อ
1. **ระดับน้ำกลั่นแบตเตอร์รี่** — ลูกลอยวัดระดับน้ำกลั่นลอยปกติ อยู่ระหว่างค่า Max-Min
2. **ขั้วแบตเตอร์รี่** — ขั้วต่อแน่น สะอาด ปราศจากคราบขี้เกลือสะสม ฝาครอบขั้วปิดเรียบร้อย
3. **ปลั๊กชาร์จไฟ** — หัวปลั๊ก (Connector) ไม่แตกร้าว ขั้วทองแดงด้านในไม่ไหม้เกรียม เสียบต่อแน่นหนา
4. **เสาและงา** — งาไม่คดงอหรือแตกร้าว ปลายงาได้ระดับระนาบเดียวกัน สลักล็อกงาล็อกแน่น เสายกไม่ติดขัด
5. **สภาพโซ่** — ความตึงโซ่ยกต้องเท่ากันทั้ง 2 ข้าง ไม่หย่อน มีการหล่อลื่นเหมาะสม
6. **สภาพล้อ + ยาง** — ยางตัน/ยางโพลียูรีเทนไม่แตกบิ่น ไม่แตกลายงา น็อตขันแน่นครบทุกตัว
7. **ระดับน้ำมันไฮดรอลิค** — วางงาลงต่ำสุด เช็คระดับน้ำมันในถังไฮดรอลิคให้อยู่ในขีดปกติ Max-Min ไม่มีคราบรั่วซึม
8. **สภาพสายไฮดรอลิค** — สายไฮดรอลิคไม่ปริแตก ไม่บวม ข้อต่อท่อไม่มีน้ำมันหยดหรือซึม
9. **ระบบไฟสัญญาณ + แตร** — ไฟส่องสว่างหน้า ไฟถอย ไฟกะพริบเตือน และแตรทำงานปกติทุกฟังก์ชัน เสียงชัดเจน
10. **ระบบเบรค** — แป้นเบรคทำงานปกติ ระบบเบรคไฟฟ้า/เบรคมือล็อกอยู่สนิทเมื่อจอดหรือปล่อยคันเร่ง

#### 2.2 รถยกไฟฟ้าประเภท Walkie stacker (รถยกแบบเดินตาม/สแต็กเกอร์ไฟฟ้า) — 10 ข้อ
*(ออกแบบจุดตรวจเฉพาะสำหรับรถแบบเดินตาม: ไม่มีพวงมาลัย/ไม่มีแป้นเบรคเท้า เน้นความปลอดภัยคันบังคับและสวิตช์ฉุกเฉิน)*
1. **ระดับน้ำกลั่นแบตเตอร์รี่** — ลูกลอยวัดระดับน้ำกลั่นลอยปกติ อยู่ระหว่างค่า Max-Min (หรือระดับไฟแบตเตอรี่พร้อมใช้งาน)
2. **ขั้วแบตเตอร์รี่** — ขั้วต่อแน่น สะอาด ปราศจากคราบขี้เกลือสะสม สายไฟไม่ชำรุด
3. **ปลั๊กชาร์จไฟ** — หัวปลั๊ก (Connector) ไม่แตกร้าว ขั้วเสียบแน่นหนา ไม่ไหม้เกรียม
4. **ปุ่มสวิตช์ถอยฉุกเฉินกันชน (Belly Button)** — สวิตช์ที่หัวคันบังคับทำงานปกติ กดแล้วตัวรถต้องตัดการเดินหน้าและถอยหลังทันที ไม่ติดขัด
5. **ปุ่มหยุดฉุกเฉิน (Emergency Stop)** — กดปุ่มตัดกระแสไฟฉุกเฉินแล้วระบบตัดการทำงานทันที ปลดล็อกหมุนเด้งได้ราบรื่น
6. **คันบังคับเลี้ยวและปุ่มเดินหน้า-ถอยหลัง** — ด้ามจับมั่นคง สวิตช์ปีกผีเสื้อคืนตำแหน่งกึ่งกลางเมื่อปล่อย การเลี้ยวซ้าย-ขวาคล่องตัว
7. **ระบบเบรค (Dead-man Brake)** — ปล่อยคันบังคับดีดขึ้นบนสุด หรือกดลงต่ำสุด ตัวรถต้องเบรคและหยุดสนิททันที
8. **เสาและงา** — งาทั้งสองข้างไม่คดงอหรือแตกร้าว ปลายงาเสมอกัน สลักล็อกงาอยู่ครบ เสาเลื่อนขึ้น-ลงราบเรียบ
9. **สภาพโซ่** — ความตึงโซ่ยกต้องเท่ากันทั้ง 2 ข้าง ไม่หย่อน มีการหล่อลื่นเหมาะสม
10. **สภาพล้อและระบบไฮดรอลิก** — ล้อขับและล้อรับน้ำหนักไม่แตกบิ่น ระดับน้ำมันไฮดรอลิคปกติ ไม่มีรอยรั่วซึม

## 🚀 วิธีตั้งค่า Google Sheets และ Google Apps Script

1. **สร้าง Google Sheet**:
   - นำไฟล์ `ระบบตรวจเช็คโฟล์คลิฟท์.xlsx` ไปอัปโหลดขึ้น Google Drive แล้วเปิดเป็น Google Sheets (หรือสร้าง Google Sheet ใหม่แล้วตั้งชื่อชีตตามนี้: `Employees`, `Forklift` (มีคอลัมน์ `Vehicle_Type` สำหรับแยกประเภท Reach truck / Walkie stacker / Counter balance), `Checklist`, `Inspection_Logs`, `Management`, `Cleaning`)
2. **เปิด Apps Script**:
   - ใน Google Sheet ไปที่เมนู **ส่วนขยาย (Extensions)** > **Apps Script**
   - ลบโค้ดเดิมออกทั้งหมด แล้วคัดลอกโค้ดจากไฟล์ `backend/Code.gs` ไปวาง
   - กดบันทึก (Save 💾)
3. **เตรียมข้อมูลเริ่มต้น (Seed Data)**:
   - ที่แถบด้านบนของ Apps Script เลือกฟังก์ชัน `seedForkliftSample` แล้วกด **เรียกใช้ (Run)** (ถ้าชีต Checklist/Cleaning มีข้อมูลอยู่แล้วจะไม่ทำงานและแจ้งเตือน ต้องการล้างแล้วสร้างใหม่ให้รัน `seedForkliftSampleForce` — ระวัง: ข้อมูลเดิมจะหาย) เพื่อสร้างข้อมูลพนักงาน รถโฟล์คลิฟท์ และรายการตรวจทั้ง 14 และ 10 ข้อ
   - (ตัวเลือกเพิ่มเติม) เลือกฟังก์ชัน `seedTestData` แล้วกด **เรียกใช้ (Run)** เพื่อสร้างประวัติการตรวจทดสอบ 7 วันสำหรับดู Dashboard
4. **Deploy เป็น Web App เพื่อรับ API**:
   - คลิกปุ่มสีน้ำเงิน **ทำให้ใช้งานได้ (Deploy)** > **การทำให้ใช้งานได้รายการใหม่ (New deployment)**
   - คลิกที่รูปฟันเฟือง ⚙️ เลือกประเภท **เว็บแอป (Web app)**
   - ตั้งค่าดังนี้:
     - **คำอธิบาย (Description):** Forklift Inspection API
     - **ดำเนินการในฐานะ (Execute as):** ฉัน (Me)
     - **ผู้มีสิทธิ์เข้าถึง (Who has access):** ทุกคน (Anyone) *(สำคัญมาก! เพื่อให้เว็บจากภายนอกหรือ GitHub Pages ส่งข้อมูลมาบันทึกได้)*
   - คลิก **ทำให้ใช้งานได้ (Deploy)** และคัดลอก **URL เว็บแอป (Web app URL)** ไว้ เช่น `https://script.google.com/macros/s/.../exec`
5. **ผูก URL ในโค้ด (ไม่ต้องกดตั้งค่าในหน้าเว็บ):**

## 💻 วิธีเปิดใช้งานใน VS Code และโฮสต์บน GitHub Pages

### 1. เปิดทดสอบใน VS Code
- เปิดโฟลเดอร์ `Forklift Inspection` ใน VS Code
- ติดตั้งส่วนขยาย **Live Server** (โดย Ritwick Dey)
- คลิกขวาที่ไฟล์ `index.html` > เลือก **Open with Live Server**
- เมื่อหน้าเว็บเปิดขึ้น:
  - สามารถทดสอบเข้าสู่ระบบได้ทันที (ใช้ PIN: `1234` สำหรับพนักงานขับรถ, `9999`/`0000` สำหรับแผนกซ่อมบำรุง)
  - ตรวจสอบว่าใส่ Web App URL ที่ `js/config.js` แล้ว (สถานะมุมขวาบนจะแสดง "Google Sheet ออนไลน์")

### 2. โฮสต์ขึ้น GitHub Pages
1. สร้าง New Repository ใน [GitHub](https://github.com)
2. อัปโหลดไฟล์ทั้งหมดขึ้น Repository:
   ```bash
   git init
   git add .
   git commit -m "Initial commit for Forklift Inspection System"
   git branch -M main
   git remote add origin <URL-GITHUB-REPO-ของคุณ>
   git push -u origin main
   ```
3. เปิดไปที่ **Settings** ของ Repository บน GitHub > เมนู **Pages**
4. ที่ส่วน **Build and deployment**:
   - Source: เลือก **Deploy from a branch**
   - Branch: เลือก **main** และโฟลเดอร์ **/ (root)**
   - กด **Save**
5. รอ 1-2 นาที คุณจะได้ URL เว็บไซต์ เช่น `https://<username>.github.io/<repo-name>/`
6. ตรวจสอบว่าใส่ Web App URL ใน `js/config.js` ก่อนอัปโหลด แล้วเปิดหน้าเว็บเพื่อใช้งานได้ทันที
