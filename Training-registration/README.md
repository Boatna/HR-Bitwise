# ระบบใบสมัครเข้ารับการฝึกอบรมฝีมือแรงงาน / ทดสอบมาตรฐานฝีมือแรงงาน (HR Bitwise Group)

เว็บแอปพลิเคชันลงทะเบียนสมัครเข้ารับการฝึกอบรมฝีมือแรงงานและทดสอบมาตรฐานฝีมือแรงงานแห่งชาติ (กรมพัฒนาฝีมือแรงงาน กระทรวงแรงงาน ร่วมกับ กลุ่ม HR Bitwise Group) รองรับการเปิดใน VS Code, ใช้งานผ่าน GitHub Pages และเชื่อมต่อ Google Sheets ผ่าน Google Apps Script

---

## 🌟 โครงสร้างไฟล์และการเข้าใช้งาน

ระบบได้แยกหน้าการใช้งานออกเป็น 2 หน้าอย่างชัดเจน เพื่อความปลอดภัยและความเป็นมืออาชีพ:

1. **หน้ารับสมัครสำหรับผู้สมัครทั่วไป (`index.html`):**
   - แบบฟอร์มใบสมัครราชการ (กพร.) สำหรับผู้ต้องการสมัครฝึกอบรม
   - กรอกข้อมูลส่วนบุคคล, ที่อยู่ (Dropdown 77 จังหวัด), วุฒิการศึกษา, แนบไฟล์หลักฐาน
   - สถานภาพแรงงานแบบปรับเปลี่ยนอัตโนมัติ (**ทำงาน** หรือ **ว่างงาน**)
   - ความยินยอม PDPA
   - เมื่อส่งใบสมัครสำเร็จ จะมีปุ่มสั่งพิมพ์ (Print) ลงกระดาษ A4 หรือดาวน์โหลด PDF ได้ทันที
   - **ไม่มีปุ่มแอดมินแสดงในหน้านี้** ป้องกันผู้สมัครทั่วไปเข้าถึงข้อมูล

2. **หน้าระบบผู้ดูแลระบบและแอดมิน (`admin.html`):**
   - มีระบบ **PIN Lock Mobile 6 หลัก** ป้องกันการเข้าถึง (**รหัสผ่านตั้งต้น: `123456`**)
     - ⚠️ **สำคัญ:** กรุณาเปลี่ยนรหัส PIN เริ่มต้นทันทีหลังติดตั้งระบบ โดยแก้ไขค่าในแผ่นงาน (sheet) **`Managers`** บน Google Sheet — เพิ่ม/แก้แถวผู้ดูแลระบบและตั้งรหัส PIN 6 หลักของแต่ละคนเอง อย่าใช้ `123456` ต่อในระบบจริง
   - ระบบมีเพียง **2 แท็บ** เท่านั้น: **"📅 ปฏิทินการดำเนินการสอน"** และ **"👥 ข้อมูลผู้สมัคร & สถานะเข้าเรียน"** (ปัจจุบันยังไม่มีแท็บ/หน้าตั้งค่าสำหรับกรอก Web App URL ผ่าน UI — ดูวิธีตั้งค่าในหัวข้อ "การเชื่อมต่อ Google Sheets" ด้านล่าง)
   - **ปฏิทินการดำเนินการสอน 2 Column สัมพันธ์กัน:**
     - **Column ซ้าย:** ปฏิทินรายเดือน ตกแต่งสวยงาม หัวชื่อวันมีพื้นหลังสีฟ้า ไฮไลต์วันที่มีการบันทึกกิจกรรม สามารถคลิกวันที่เพื่อดูรายละเอียดหรือเพิ่มกิจกรรมได้
     - **Column ขวา:** ตารางแสดงกิจกรรมของเดือนนั้น (วันที่ภาษาไทย, การดำเนินงาน/กิจกรรม, ผู้รับผิดชอบ)
   - **ตารางจัดการผู้สมัคร & สถานะเข้าเรียน:**
     - แสดงรายชื่อผู้สมัคร, ค้นหา, กรองสถานะ
     - ปุ่มคลิกเปลี่ยนสถานะ: **"ได้เข้ามาเรียนแล้ว"** (สีเขียว) / **"ยังไม่มา"** (สีส้ม)
     - ปุ่มดูตัวอย่างและสั่งพิมพ์ PDF แบบฟอร์มราชการ
     - กระดิ่งแจ้งเตือนผู้สมัครใหม่ — อัปเดตอัตโนมัติทุกครั้งที่ล็อกอินด้วย PIN หรือกดปุ่ม **"🔄 รีเฟรชจาก Google Sheet"** (ไม่ใช่การแจ้งเตือนแบบเรียลไทม์/พุชอัตโนมัติขณะเปิดหน้าจอค้างไว้)
   - เมื่อกด **"🔒 ล็อคระบบ"** ระบบจะล้างข้อมูลผู้สมัคร/ปฏิทินที่แคชไว้ในเครื่องออกจากหน่วยความจำและ localStorage ทั้งหมด ต้องกรอก PIN และซิงก์ข้อมูลใหม่ทุกครั้งที่ล็อกอิน (เพื่อความปลอดภัยของข้อมูลส่วนบุคคลผู้สมัคร)

## 🚀 วิธีการเปิดใช้งานใน VS Code

1. เปิดโปรแกรม **VS Code**
2. ไปที่เมนู `File` -> `Open Folder...` แล้วเลือกโฟลเดอร์นี้ (`skill-training-registration`)
3. การเปิดใช้งาน:
   - **หน้ารับสมัคร:** คลิกขวาที่ `index.html` -> เลือก **"Open with Live Server"** หรือเปิดผ่านเบราว์เซอร์
   - **หน้าแอดมิน:** เปิดไฟล์ `admin.html` ผ่านเบราว์เซอร์ แล้วกดรหัส PIN: `123456` (หรือ PIN ที่ตั้งไว้เองในแผ่นงาน Managers)

## 🌐 วิธีนำขึ้นโฮสต์บน GitHub Pages

1. นำไฟล์ในโฟลเดอร์นี้อัปโหลดขึ้น GitHub Repository ของท่าน
2. ไปที่หน้า Repository บน GitHub -> คลิกแท็บ **Settings**
3. ที่เมนูด้านซ้ายเลือก **Pages**
4. ในส่วน **Build and deployment**:
   - Source: เลือก **Deploy from a branch**
   - Branch: เลือก **main** หรือ **master** และโฟลเดอร์เป็น **/(root)**
5. กด **Save** รอประมาณ 1-2 นาที จะได้ URL เช่น:
   - หน้ารับสมัคร: `https://username.github.io/repository-name/` หรือ `.../index.html`
   - หน้าแอดมิน: `https://username.github.io/repository-name/admin.html`

> หมายเหตุ: เมื่อโฮสต์บน GitHub Pages หน้า `admin.html` จะเข้าถึงได้แบบสาธารณะเช่นกัน (แต่ข้อมูลจริงถูกป้องกันด้วยรหัส PIN + session token ฝั่งเซิร์ฟเวอร์ ไม่ใช่แค่การซ่อนหน้าเว็บ) จึงยังคงต้องตั้ง PIN ที่คาดเดายากและเก็บ URL ของ Repository ไว้เป็นความลับตามความเหมาะสม

## 📊 การเชื่อมต่อ Google Sheets ผ่าน Google Apps Script

1. สร้าง Google Sheet ใหม่ขึ้นมา 1 ไฟล์
2. ไปที่เมนู **ส่วนขยาย (Extensions)** -> **Apps Script**
3. คัดลอกโค้ดทั้งหมดในไฟล์ `google-apps-script/Code.gs` ไปวางแทนที่โค้ดเดิมใน Apps Script แล้วกด Save (💾)
4. แก้ไขค่า `SPREADSHEET_ID` และ `DRIVE_FOLDER_ID` ที่ต้นไฟล์ `Code.gs` ให้เป็นของ Google Sheet และโฟลเดอร์ Google Drive ของท่านเอง
5. เลือกฟังก์ชัน **`setupSheets`** แล้วกดปุ่ม **"เรียกใช้" (Run)** 1 ครั้ง -> ระบบจะสร้างแผ่นงาน `Applicants`, `CalendarEvents` และ `Managers` พร้อมหัวตารางภาษาไทยให้อัตโนมัติทันที (แผ่นงาน `Managers` จะมีแถวตัวอย่าง PIN `123456` มาให้ — **ให้แก้เป็น PIN ของจริงทันที**)
6. คลิกปุ่ม **การทำให้ใช้งานได้ (Deploy)** ที่มุมขวาบน -> เลือก **การทำให้ใช้งานได้รายการใหม่ (New deployment)**
7. คลิกไอคอนฟันเฟือง ⚙️ เลือกประเภทเป็น **เว็บแอป (Web app)**
   - คำอธิบาย: `HR Bitwise Skill API`
   - เรียกใช้ในฐานะ: **ฉัน (Me)**
   - ผู้มีสิทธิ์เข้าถึง: **ทุกคน (Anyone)**
8. คลิก **ทำให้ใช้งานได้ (Deploy)** -> คัดลอก **URL เว็บแอป (Web app URL)**
9. เปิดไฟล์ **`gs-api.js`** ด้วย VS Code แล้วแก้ค่าตัวแปร `DEFAULT_GAS_WEB_APP_URL` ให้เป็น URL ที่คัดลอกมาในข้อ 8:
   ```js
   const DEFAULT_GAS_WEB_APP_URL = 'วาง URL เว็บแอปของคุณตรงนี้';
   ```
   > ปัจจุบันหน้า `admin.html` ยังไม่มีช่องกรอก Web App URL ผ่านหน้าจอ (แม้ในโค้ดจะมีฟังก์ชัน `setGasWebAppUrl()` เตรียมไว้ก็ตาม) จึงต้องแก้ค่าคงที่นี้ในไฟล์โดยตรงแล้วอัปโหลดไฟล์ขึ้นไปทับของเดิมบน GitHub Pages/โฮสต์ของท่าน
10. บันทึกไฟล์แล้วรีเฟรชหน้าเว็บ ระบบจะเรียกใช้ Web App URL ใหม่ทันที

### 🔁 เมื่อแก้ไขโค้ด `Code.gs` ในภายหลัง
ทุกครั้งที่แก้ไขโค้ดใน Apps Script (`Code.gs`) แล้วต้องการให้ URL เว็บแอปเดิมใช้โค้ดเวอร์ชันใหม่ **ต้อง Deploy ซ้ำเสมอ**:
`Deploy` -> `Manage deployments` -> กดไอคอนดินสอ (แก้ไข) ที่ deployment เดิม -> เลือก **Version: New version** -> กด **Deploy**
(การกด Save 💾 เฉยๆ ในหน้า Apps Script editor จะไม่อัปเดตโค้ดที่ URL เดิมกำลังรันอยู่)
