# ระบบบริหารหอพักพนักงาน (Employee Dormitory Management System) v2.0

ระบบบริหารจัดการหอพักพนักงานองค์กรแบบเข้าใจง่าย ไม่ซับซ้อน ใช้งานผ่านเว็บเบราว์เซอร์ เชื่อมต่อฐานข้อมูล Google Sheets ผ่าน Google Apps Script Web API

---

## 🌟 จุดประสงค์หลักของระบบ (Core Objectives)

ระบบนี้ออกแบบมาเพื่อตอบโจทย์การใช้งานจริงของ HR อย่างตรงไปตรงมา:
1. **เก็บข้อมูลว่าพนักงานคนไหนพักอยู่ห้องไหน (Employee Occupancy):** เช็คอิน ย้ายห้อง และเช็คเอาท์ได้สะดวกรวดเร็ว ป้องกันการเช็คอินซ้อน (พนักงาน 1 คน มีห้องพัก Active ได้ห้องเดียว)
2. **ตรวจสอบว่าห้องพักว่างหรือเปล่าแบบ Real-time (Room Vacancy Status):**
   - 🟢 **ว่าง (Available):** ยังไม่มีผู้พัก (0 คน) พร้อมให้พนักงานเข้าพักได้ทันที
   - 🟡 **ว่างบางส่วน (Partially Occupied):** มีผู้พักแล้ว แต่ยังไม่เต็มความจุห้อง (เช่น พัก 1 คน จากความจุ 2 คน)
   - 🔴 **เต็ม (Full):** มีผู้พักเต็มตามความจุของห้อง
   - 🟠 **ปิดปรับปรุง (Maintenance):** ห้องอยู่ระหว่างปิดซ่อมบำรุง สามารถกดสลับเปิด/ปิดได้ในคลิกเดียว
3. **เฟอร์นิเจอร์มาตรฐานเหมือนกันทุกห้อง:** ทุกห้องพักมีชุดเฟอร์นิเจอร์มาตรฐานและเครื่องปรับอากาศครบชุดเหมือนกันทั้งหมด จึงไม่มีความจำเป็นต้องกรอกหรือบันทึกทะเบียนทรัพย์สินแยกรายชิ้นให้ยุ่งยาก

## 🔒 ฐานข้อมูล Google Sheets (Database Schema)

โครงสร้างฐานข้อมูลปรับปรุงใหม่ให้เข้าใจง่าย มีเพียง **5 ตารางหลัก**:

| แผ่นงาน (Sheet) | ข้อมูลที่จัดเก็บ |
|:---|:---|
| **`Rooms`** | ข้อมูลห้องพัก (รหัสห้อง, อาคาร, ชั้น, เลขห้อง, ประเภทห้อง, ความจุ, เพศผู้พัก, ค่าเช่า, สถานะ, หมายเหตุ) *ทุกห้องมีเฟอร์นิเจอร์มาตรฐานครบชุด* |
| **`Employees`** | ข้อมูลพนักงาน (รหัสพนักงาน, คำนำหน้า, ชื่อ, นามสกุล, ชื่อเต็ม, แผนก, ตำแหน่ง, โรงงาน, เบอร์โทร, อีเมล, สถานะ) |
| **`Occupancy`** | ข้อมูลการเข้าพักจริง (รหัสการเข้าพัก, รหัสพนักงาน, รหัสห้อง, ที่พัก/เตียง, วันที่เข้าพัก, วันที่ย้ายออก, สถานะ, หมายเหตุ) |
| **`Buildings`** | ข้อมูลอาคารหอพัก (รหัสอาคาร, ตัวย่ออาคาร, ชื่ออาคาร, ที่ตั้ง, จำนวนชั้น, สถานะ, หมายเหตุ) |
| **`Settings`** | การตั้งค่าระบบ (ชื่อหอพัก, องค์กร, รายการเฟอร์นิเจอร์มาตรฐาน) |

## 🚀 ขั้นตอนการติดตั้งและเชื่อมต่อระบบ (Setup Guide)

### ขั้นตอนที่ 1: สร้างฐานข้อมูล Google Sheets อัตโนมัติ
1. ไปที่ [Google Sheets](https://sheets.new) เพื่อสร้าง Spreadsheet ว่างใหม่ 1 ไฟล์
2. ตั้งชื่อไฟล์ตามต้องการ เช่น `Dormitory_Database_Bitwise`
3. ไปที่เมนู **ส่วนขยาย (Extensions)** > **Apps Script**
4. ลบโค้ดเดิมใน Apps Script ออกทั้งหมด
5. คัดลอกโค้ดจากไฟล์ `google-apps-script/setup_sheets.gs` ไปวาง
6. เลือกฟังก์ชัน **`setupDormitoryDatabase`** ที่แถบเครื่องมือด้านบน แล้วกดปุ่ม **เรียกใช้ (Run)**
7. กดยืนยันการอนุญาตสิทธิ์ (Review Permissions) เมื่อมีป๊อปอัปแจ้งเตือน
8. ระบบจะสร้างแผ่นงานครบทั้ง 5 ตารางพร้อมข้อมูลตัวอย่างเริ่มต้นทันที

---

### ขั้นตอนที่ 2: ติดตั้ง Web API Backend (`Code.gs`)
1. ในหน้าต่าง Google Apps Script เดิม ให้ลบโค้ดออก แล้วคัดลอกโค้ดจากไฟล์ `google-apps-script/Code.gs` ไปวางแทนที่
2. กดปุ่มบันทึก (ไอคอนแผ่นดิสก์ หรือ `Ctrl+S`)
3. คลิกปุ่มสีน้ำเงิน **ทำให้ใช้งานได้ (Deploy)** ที่มุมขวาบน > เลือก **การทำให้ใช้งานได้ใหม่ (New deployment)**
4. คลิกไอคอนฟันเฟือง ⚙️ ด้านซ้าย > เลือกประเภท **เว็บแอป (Web app)**
5. ตั้งค่าดังนี้:
   - **คำอธิบาย (Description):** `Dormitory API v2.0`
   - **ดำเนินการในฐานะ (Execute as):** **ฉัน (Me)**
   - **ผู้มีสิทธิ์เข้าถึง (Who has access):** **ทุกคน (Anyone)** *(สำคัญมาก เพื่อให้หน้าเว็บเรียก API ได้โดยไม่ต้องล็อกอินบัญชี Google)*
6. คลิกปุ่ม **ทำให้ใช้งานได้ (Deploy)**
7. คัดลอก **URL เว็บแอป (Web app URL)** ที่ได้มา (รูปแบบ: `https://script.google.com/macros/s/XXXXX/exec`)

---

### ขั้นตอนที่ 3: นำ API URL มาใส่ในระบบ Frontend
1. เปิดหน้าเว็บ `admin.html` บนเบราว์เซอร์
2. ไปที่เมนู **การตั้งค่า (Settings)** ด้านซ้าย
3. วาง Web App URL ที่ได้จากขั้นตอนที่ 2 ลงในช่อง "Web App URL"
4. กดปุ่ม **"บันทึก URL เชื่อมต่อ"** และสามารถกด **"ทดสอบการเชื่อมต่อ"** เพื่อตรวจเช็คความพร้อม
5. ระบบจะบันทึก URL ไว้ในเบราว์เซอร์ของคุณ และเชื่อมต่อกับ Google Sheets ทันที!

## 🛡️ กฎการทำงานของระบบ (Business Logic)

1. **คำนวณสถานะห้องอัตโนมัติ:** สถานะห้องจะคำนวณจากจำนวนคนเข้าพักจริงเทียบกับความจุห้อง และสถานะปิดปรับปรุง เสมอ
2. **ห้ามเช็คอินซ้อน:** พนักงาน 1 คน มีห้องพัก Active ได้เพียงห้องเดียวเท่านั้น หากต้องการเปลี่ยนห้อง ให้ใช้ปุ่ม "ย้ายห้อง" (Transfer)
3. **ห้ามเช็คอินเกินความจุ:** หากห้องพักเต็มแล้ว ระบบจะแจ้งเตือนและไม่อนุญาตให้เช็คอินเพิ่ม
4. **ปิดปรับปรุงในคลิกเดียว:** ผู้ดูแลสามารถกดสลับสถานะ "ปิดปรับปรุง / เปิดใช้งาน" ได้โดยตรงจากหน้าห้องพัก โดยห้องที่ปิดปรับปรุงจะแสดงเป็นสีส้มและไม่อนุญาตให้เช็คอิน
5. **การย้ายออก (Check-out):** เมื่อกดเช็คเอาท์ ระบบจะบันทึกวันที่ย้ายออกและคืนสถานะห้องให้กลายเป็นห้อง "ว่าง" พร้อมให้พนักงานคนอื่นเข้าพักได้ทันที
