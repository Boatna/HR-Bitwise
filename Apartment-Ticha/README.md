# ระบบบริหารหอพักพนักงาน (Employee Dormitory Management System) v2.5.0

ระบบบริหารจัดการหอพักพนักงานองค์กรแบบเข้าใจง่าย ไม่ซับซ้อน ใช้งานผ่านเว็บเบราว์เซอร์ เชื่อมต่อฐานข้อมูล Google Sheets ผ่าน Google Apps Script Web API

---

## 🌟 จุดประสงค์หลักของระบบ (Core Objectives)

ระบบนี้ออกแบบมาเพื่อตอบโจทย์การใช้งานจริงของ HR อย่างตรงไปตรงมา:
1. **เก็บข้อมูลว่าพนักงานคนไหนพักอยู่ห้องไหน (Employee Occupancy):** เช็คอิน ย้ายห้อง และเช็คเอาท์ได้สะดวกรวดเร็ว ป้องกันการเช็คอินซ้อน (พนักงาน 1 คน มีห้องพัก Active ได้ห้องเดียว)
2. **ตรวจสอบว่าห้องพักว่างหรือเปล่าแบบ Real-time (Room Vacancy Status):**
   - 🟢 **ว่าง (Available):** ยังไม่มีผู้พัก (0 คน) พร้อมให้พนักงานเข้าพักได้ทันที
   - 🟡 **ว่างบางส่วน (Partially Occupied):** มีผู้พักแล้ว แต่ยังไม่เต็มความจุห้อง (เช่น พัก 1 คน จากความจุ 2 คน)
   - 🔴 **เต็ม (Full):** มีผู้พักเต็มตามความจุของห้อง
   - 🟠 **ปิดปรับปรุง (Maintenance):** ห้องอยู่ระหว่างปิดซ่อมบำรุง สามารถกดสลับเปิด/ปิดได้ในคลิกเดียว
3. **ระบบการจองที่จอดรถแบบยืดหยุ่น (Hybrid Parking Management):**
   - รองรับทั้ง **พนักงานที่พักอยู่ในหอพัก** (ระบบเชื่อมโยงห้องพักให้อัตโนมัติและคืนช่องจอดเมื่อเช็คเอาท์) และ **พนักงานทั่วไป** (จองที่จอดรถตามปกติโดยไม่ต้องมีห้องพัก)
   - รองรับทั้งรถยนต์ (Car) และรถจักรยานยนต์ (Motorcycle)
   - บันทึกเลขทะเบียนรถ ยี่ห้อ/รุ่น โซน และวันที่เริ่มจอง
   - มีระบบจองช่องจอด คืนช่องจอด และอัปเดตห้องพักให้อัตโนมัติเมื่อพนักงานย้ายห้อง
4. **จัดการครุภัณฑ์ประจำห้องพักและระบบปรับอากาศ (Room Assets & Facilities):**
   - กำหนดได้รายห้องว่ามี **เครื่องปรับอากาศ (ห้องแอร์)** หรือ **พัดลม (ไม่มีเครื่องปรับอากาศ)**
   - มี **หน้าจัดการ Asset ประจำห้องพักแบบตาราง** สามารถดูข้อมูล, เพิ่ม, ลบ, แก้ไข และกรองตามห้อง/อาคาร/สถานะได้
   - มีปุ่มสร้างชุดครุภัณฑ์มาตรฐานเข้าห้องพักอัตโนมัติ 1 คลิก (ปรับเปลี่ยนแอร์/พัดลม และจำนวนเตียง/ตู้ตามความจุห้อง)

## 🔒 ฐานข้อมูล Google Sheets (Database Schema)

โครงสร้างฐานข้อมูลออกแบบให้เข้าใจง่าย ประกอบด้วย **10 ตาราง** (8 ตารางหลัก + `MeterReadings`, `Bills` สำหรับมิเตอร์/บิล):

| แผ่นงาน (Sheet) | ข้อมูลที่จัดเก็บ |
|:---|:---|
| **`Rooms`** | ข้อมูลห้องพัก (รหัสห้อง, อาคาร, ชั้น, เลขห้อง, ประเภทห้อง, ความจุ, เพศผู้พัก, ค่าเช่า, **HasAirConditioner (มีแอร์ Yes/No)**, สถานะ, หมายเหตุ) |
| **`Employees`** | ข้อมูลพนักงาน (รหัสพนักงาน, คำนำหน้า, ชื่อ, นามสกุล, ชื่อเต็ม, แผนก, ตำแหน่ง, โรงงาน, เบอร์โทร, อีเมล, สถานะ) |
| **`Occupancy`** | ข้อมูลการเข้าพักจริง (รหัสการเข้าพัก, รหัสพนักงาน, รหัสห้อง, รหัสเตียง, เลขเตียง, วันที่เข้าพัก, วันที่ย้ายออก, สถานะ, หมายเหตุ) |
| **`Parking`** | ข้อมูลการจองที่จอดรถ (รหัสช่อง, เลขช่องจอด, โซน, ประเภทรถยนต์/มอเตอร์ไซค์, สถานะ, รหัสพนักงานผู้จอง, รหัสห้องพัก/NON_RESIDENT, เลขทะเบียนรถ, รุ่น/ยี่ห้อ, วันที่เริ่มจอง, หมายเหตุ) |
| **`Assets`** | ข้อมูลครุภัณฑ์/เฟอร์นิเจอร์ประจำห้องพัก (รหัส Asset, รหัสห้องพัก, ชื่อครุภัณฑ์, รหัสทรัพย์สิน, หมวดหมู่, จำนวน, สถานะ, สภาพการใช้งาน, หมายเหตุ) |
| **`Buildings`** | ข้อมูลอาคารหอพัก (รหัสอาคาร, ตัวย่ออาคาร, ชื่ออาคาร, ที่ตั้ง, จำนวนชั้น, สถานะ, หมายเหตุ) |
| **`Settings`** | การตั้งค่าระบบ (ชื่อหอพัก, องค์กร, รายการเฟอร์นิเจอร์มาตรฐาน, อีเมล) |
| **`AuditLog`** | ประวัติการทำรายการในระบบ (รหัสล็อก, เวลา, อีเมลผู้ใช้, การกระทำ, โมดูล, รหัสรายการ, หมายเหตุ) |
| **`MeterReadings`** | เลขมิเตอร์ไฟ/น้ำรายห้องรายงวด (รหัส, ห้อง, งวด yyyy-MM, เลขก่อน/หลัง, หน่วยที่ใช้, วนครบรอบ, วันที่จด, ผู้จด) |
| **`Bills`** | ใบแจ้งหนี้/ใบเสร็จ (เลขที่บิล INV-, เลขที่ใบเสร็จ RC-, ยอดค่าไฟ/น้ำ/เช่า/VAT/รวม, สถานะ Unpaid/Paid/Cancelled, ใบเสร็จที่ถูกยกเลิก) |

## 🚗 คำแนะนำการบริหารจัดการที่จอดรถ (Parking Architecture & Recommendations)

ระบบรองรับ 2 รูปแบบการจอง เพื่อความยืดหยุ่นสูงสุดของ HR:

1. **กรณีพนักงานพักหอพัก (Resident):**
   - เมื่อเลือกพนักงานพักหอพัก ระบบจะดึงห้องพักให้อัตโนมัติ
   - เมื่อย้ายห้อง (Transfer) ช่องจอดจะอัปเดตห้องใหม่ให้อัตโนมัติ
   - เมื่อเช็คเอาท์ (Check-out) ระบบจะคืนช่องจอดให้อัตโนมัติ (ยกเว้นพนักงานประสงค์เปลี่ยนสถานะเป็นพนักงานทั่วไป)
2. **กรณีพนักงานทั่วไป (Non-Resident / ไป-กลับ):**
   - พนักงานที่ไม่ได้พักในหอพัก สามารถจองช่องจอดรถได้ตามปกติ ระบบจะบันทึกเป็นกลุ่ม "พนักงานทั่วไป"
   - ช่องจอดของพนักงานทั่วไปจะไม่ถูกคืนเมื่อมีผู้พักห้องอื่นเช็คเอาท์
   - แนะนำให้จัดโซนช่องจอด (Zone) แยกอย่างชัดเจน เช่น "โซนหอพัก A/B" สำหรับผู้พักหอ และ "โซนลานจอดทั่วไป" สำหรับพนักงานไป-กลับ

## 🚀 ขั้นตอนการติดตั้งและเชื่อมต่อระบบ (Setup Guide)

### ขั้นตอนที่ 1: สร้างหรืออัปเดตฐานข้อมูล Google Sheets
1. หากเริ่มสร้างใหม่: เปิด Google Sheets เปล่า รันฟังก์ชัน **`setupDormitoryDatabase`** ใน `setup_sheets.gs`
2. **หากมีข้อมูลเดิมอยู่แล้ว (ไม่อยากให้ข้อมูลหาย):**
   - นำโค้ด `Code.gs` ใหม่ไปวางใน Apps Script
   - สลับไปเลือกฟังก์ชัน **`ensureAllSheets`** แล้วกด **เรียกใช้ (Run)** 1 ครั้ง
   - ระบบจะเพิ่มตาราง `Assets` และเพิ่มคอลัมน์ `HasAirConditioner` ใน `Rooms` ให้โดยอัตโนมัติ โดยไม่ลบข้อมูลเดิม!

### ขั้นตอนที่ 2: ติดตั้ง Web API Backend (`Code.gs`)
1. ใน Google Apps Script กดปุ่ม **ทำให้ใช้งานได้ (Deploy)** > **การทำให้ใช้งานได้ใหม่ (New deployment)** (หรือ Edit > New version สำหรับ URL เดิม)
2. เลือกประเภท **เว็บแอป (Web app)**
3. ตั้งค่า **ผู้มีสิทธิ์เข้าถึง (Who has access):** **ทุกคน (Anyone)**
4. คัดลอก Web app URL มาบันทึกในหน้า `admin.html` > การตั้งค่า (Settings)

- `saveSettings` ตรวจค่าตัวเลขของอัตรา/VAT/วันครบกำหนด
- `addDefaultAssetsForRoom` กันสร้างชุดครุภัณฑ์มาตรฐานซ้ำในห้องเดิม
