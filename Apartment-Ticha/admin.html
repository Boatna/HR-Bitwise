จัดการการเข้าพัก (ใครพักห้องไหน)

ตรวจสอบรายชื่อผู้พักอาศัยปัจจุบัน เช็คอินเข้าห้อง ย้ายห้อง และเช็คเอาท์

รหัสพนักงาน ชื่อ-นามสกุล / ข้อมูลติดต่อ อาคาร เลขห้อง ที่พัก / เตียง วันที่เข้าพัก จัดการ

ข้อมูลห้องพักและสถานะ (Rooms)

จัดการห้องพัก ความจุผู้พัก และสลับสถานะเปิดใช้งาน / ปิดปรับปรุงห้อง

หมายเหตุเฟอร์นิเจอร์: ห้องพักทุกห้องมีเฟอร์นิเจอร์มาตรฐานครบชุดเหมือนกันหมด (เตียงนอน, ที่นอน, ตู้เสื้อผ้า, โต๊ะทำงาน, เก้าอี้, เครื่องปรับอากาศ)
เลขห้อง อาคาร ชั้น ประเภท ความจุ ผู้พักจริง / ว่าง สถานะห้อง จัดการ

ข้อมูลพนักงาน (Employees)

จัดการรายชื่อพนักงาน ข้อมูลติดต่อ และสถานะห้องพักปัจจุบัน

รหัส ชื่อ-นามสกุล แผนก ตำแหน่ง เบอร์โทร ห้องพักปัจจุบัน จัดการ

จองที่จอดรถ (ช่องนี้ของใคร / พักห้องไหน)

จองช่องจอดให้พนักงานที่พักอยู่ในหอ ระบบดึงห้องพักให้อัตโนมัติ และคืนช่องให้เองเมื่อเช็คเอาท์

ช่องจอด ประเภท สถานะ ผู้จอง (ของใคร) พักห้อง ทะเบียน / รุ่นรถ เริ่มจอง จัดการ

ข้อมูลอาคารหอพัก

รายชื่ออาคารหอพัก จำนวนชั้น และที่ตั้ง

รายงานและส่งออกข้อมูล

สรุปข้อมูลห้องพัก ผู้พักอาศัย และส่งออกไฟล์ CSV ภาษาไทย (เปิดด้วย Excel ได้ทันที)

รายงาน

การตั้งค่าระบบ

จัดการการเชื่อมต่อ Google Sheets Web API และข้อมูลทั่วไปของหอพัก

การเชื่อมต่อ Google Apps Script Web App
URL ที่ได้จากการ Deploy เป็น Web App ใน Google Apps Script (Who has access: Anyone)
ต้องตรงกับ Script Property ชื่อ API_TOKEN ใน Apps Script (ถ้าตั้งไว้) ช่วยกันคนนอกที่รู้ URL เรียกใช้ API
ข้อมูลหอพักและองค์กร
ห้องพักทุกห้องมีเฟอร์นิเจอร์ชุดนี้เหมือนกันทั้งหมด
คำแนะนำการใช้งาน
  • บันทึกพนักงานพักห้องไหน: ไปที่แท็บ "การเข้าพัก" แล้วคลิกปุ่ม "เช็คอินพนักงานใหม่"
  • ตรวจสอบห้องว่าง: ไปที่แท็บ "ข้อมูลห้องพัก" หรือหน้า "สถานะห้องพัก"
  • ย้ายห้อง: คลิกปุ่ม "ย้ายห้อง" ที่แถวพนักงาน ระบบจะเปลี่ยนห้องให้ทันที
  • ปิดปรับปรุงห้อง: คลิกปุ่ม "ปิดปรับปรุง" ในหน้ารายการห้องพัก เมื่อซ่อมเสร็จคลิก "เปิดใช้งาน" ได้ทันที
  • จองที่จอดรถ: ไปที่แท็บ "ที่จอดรถ" กดปุ่ม "จอง" ที่ช่องว่าง เลือกพนักงาน (ระบบดึงห้องพักให้เอง) แล้วกรอกทะเบียนรถ
  • ที่จอดรถเมื่อย้าย/ออก: ย้ายห้อง = ห้องในรายการจอดอัปเดตเอง, เช็คเอาท์ = คืนช่องจอดให้อัตโนมัติ
  • ส่งออกข้อมูล: ไปที่แท็บ "รายงานและส่งออก" แล้วกด "ดาวน์โหลด CSV (Excel)"
